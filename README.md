# Эмулятор оболочки ОС

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
(tkinter, язык Python 3). Заголовок окна содержит имя VFS:
`Эмулятор - [VFS: default]` (пока VFS не подключена, используется
имя `default`).

Состояние проекта: этап 1 (REPL). Команды `ls` и `cd` пока заглушки.

Структура репозитория:

```
src/    исходный код (main.py, gui.py, shell.py, cmd_parser.py)
tests/  модульные тесты
run.bat запуск эмулятора
```

## 2. Описание функций и настроек

Ввод разбивается по пробелам: первое слово - команда, остальные -
аргументы. Пустая строка игнорируется.

| Команда     | Описание                                                |
|-------------|---------------------------------------------------------|
| `ls [args]` | заглушка: выводит `ls args: [...]`                      |
| `cd [args]` | заглушка: выводит `cd args: [...]`                      |
| `exit`      | закрывает эмулятор; с аргументами: `too many arguments` |

Неизвестная команда даёт ошибку `<name>: command not found`
(выводится красным цветом).

Приглашение ввода: `username@hostname:~$`.

## 3. Сборка и тесты

Сборка не требуется. Нужен Python 3.8+ с tkinter (входит в
стандартную установку для Windows).

Запуск эмулятора:

```
run.bat
```

Запуск тестов (из корня репозитория):

```
python -m unittest discover -s tests
```

## 4. Примеры использования

```
user@host:~$ ls
ls args: []
user@host:~$ ls -l /tmp
ls args: ['-l', '/tmp']
user@host:~$    cd    /home
cd args: ['/home']
user@host:~$ foo
foo: command not found
user@host:~$ exit 1
exit: too many arguments
user@host:~$ exit
```

После `exit` окно закрывается.
