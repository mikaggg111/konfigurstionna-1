# Эмулятор командной строки UNIX

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
на tkinter (Python 3, без сторонних библиотек). Заголовок окна строится
из реальных данных ОС: `Эмулятор - [username@hostname]`.

Состояние проекта: этап 3 (VFS). Команды `ls` и `cd` пока заглушки.

Структура репозитория:

```
src/      исходный код
tests/    модульные тесты
vfs/      примеры VFS в формате CSV (vfs/broken - неверные, для проверки)
scripts/  стартовые скрипты эмулятора и скрипты ОС для проверки
run.sh    запуск (Linux/macOS), run.bat - запуск (Windows)
Makefile  цели run и test
```

## 2. Функции и настройки

Ввод делится по пробелам: первое слово - команда, остальные - аргументы.
Пустая строка игнорируется. Ошибки показываются красным цветом.

| Команда     | Описание                                          |
|-------------|---------------------------------------------------|
| `ls [args]` | заглушка: печатает `ls args: [...]`               |
| `cd [args]` | заглушка: печатает `cd args: [...]`               |
| `exit`      | закрывает эмулятор (с аргументами - ошибка)       |
| `vfsinfo`   | служебная: имя VFS, число папок и файлов          |

Неизвестная команда: `<имя>: command not found`.

### Параметры командной строки

| Параметр          | Описание                                    |
|-------------------|---------------------------------------------|
| `--vfs ПУТЬ`      | путь к физическому расположению VFS         |
| `--script ПУТЬ`   | путь к стартовому скрипту                   |
| `--help`          | справка по параметрам                       |

При запуске все заданные параметры выводятся на экран (отладочный
вывод): в окно серым цветом и в консоль. Неизвестный параметр - ошибка
с остановкой программы.

### Стартовый скрипт

Текстовый файл (UTF-8), в каждой строке одна команда эмулятора.
`#` начинает комментарий, пустые строки пропускаются. Команды
выполняются по очереди, на экране видны и ввод, и вывод, как будто их
набирает пользователь. **Скрипт останавливается на первой ошибке**:
показывается номер строки, остальные строки не выполняются, после чего
можно продолжать вводить команды вручную. Если файл скрипта не найден,
выводится ошибка, окно работает как обычно.

Скрипты реальной ОС для проверки параметров (Windows `.bat`, Linux
`.sh`): `scripts/test_config.bat`, `scripts/test_config.sh`. Каждый
запуск открывает окно, закройте его для перехода к следующему.

### VFS (виртуальная файловая система)

Источник VFS - CSV-файл (`--vfs путь/к/файлу.csv`, UTF-8). При запуске
он целиком читается в память, дальше эмулятор работает только с памятью:
файл на диске никогда не изменяется. Имя VFS - имя CSV-файла.

Формат CSV - три столбца с заголовком `path,type,content`:

| Столбец   | Значение                                                    |
|-----------|-------------------------------------------------------------|
| `path`    | полный путь от корня, начинается с `/`, без `.` и `..`      |
| `type`    | `dir` (папка) или `file` (файл)                             |
| `content` | содержимое файла в **base64** (у папки пусто)               |

Вложенность задаётся полным путём: родитель элемента - всё, что стоит до
последнего `/`. Недостающие промежуточные папки создаются сами, а строки
`dir` нужны, чтобы описать пустую папку. Содержимое всегда в base64, так
в файле можно хранить и текст, и двоичные данные:

```
path,type,content
/docs,dir,
/docs/hello.txt,file,SGVsbG8sIHdvcmxkIQ==
/docs/archive/2025/report.txt,file,0J7RgtGH0ZHRgg==
```

Получить base64: `python -c "import base64;print(base64.b64encode(b'Hello').decode())"`.

Примеры в папке `vfs/`:

| Файл                 | Содержимое                                           |
|----------------------|------------------------------------------------------|
| `vfs/minimal.csv`    | минимальная VFS: один файл                           |
| `vfs/several.csv`    | несколько файлов и одна папка                        |
| `vfs/deep.csv`       | 5 уровней вложенности, пустая папка, двоичный файл   |
| `vfs/broken/*.csv`   | неверные файлы: проверка обработки ошибок            |

Если `--vfs` не задан, используется пустая VFS (имя `default`). Ошибки
загрузки (файл не найден, указана папка, нет столбцов, неизвестный тип,
неверный base64 или путь) выводятся красным с номером строки CSV, а
эмулятор продолжает работу с пустой VFS.

Скрипты ОС: `scripts/test_vfs.bat`, `scripts/test_vfs.sh` - запуск с
разными VFS и ошибками загрузки. Стартовый скрипт `scripts/stage3.txt`
проверяет команды этапов 1-3 и подходит для любой VFS.

## 3. Сборка и тесты

Сборка не нужна. Требуется Python 3.8+ с tkinter (на Windows он
ставится вместе с Python).

```
run.bat                                  # запуск, Windows
./run.sh                                 # запуск, Linux/macOS
python -m unittest discover -s tests -v  # тесты
```

## 4. Примеры использования

Запуск с VFS и скриптом (параметры задаются после имени скрипта запуска,
пути считаются от корня репозитория):

```
run.bat --vfs vfs\deep.csv --script scripts\stage3.txt
./run.sh --vfs vfs/deep.csv --script scripts/stage3.txt
```

Диалог в окне:

```
user@host:~$ ls -l /tmp
ls args: ['-l', '/tmp']
user@host:~$ cd /home
cd args: ['/home']
user@host:~$ foo
foo: command not found
user@host:~$ vfsinfo
VFS: deep.csv, папок: 7, файлов: 6
user@host:~$ exit now
exit: too many arguments
user@host:~$ exit
```
