# Эмулятор командной строки UNIX

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
на tkinter (Python 3, без сторонних библиотек). Заголовок окна строится
из реальных данных ОС: `Эмулятор - [username@hostname]`.

Состояние проекта: этап 2 (конфигурация). Команды `ls` и `cd` пока
заглушки.

Структура репозитория:

```
src/      исходный код
tests/    модульные тесты
scripts/  стартовые скрипты эмулятора и скрипты ОС для проверки
run.sh    запуск (Linux/macOS), run.bat - запуск (Windows)
Makefile  цели run и test
```

## 2. Функции и настройки

Ввод делится по пробелам: первое слово - команда, остальные - аргументы.
Пустая строка игнорируется. Ошибки показываются красным цветом.

| Команда     | Описание                                          |
|-------------|---------------------------------------------------|
| `ls [args]` | заглушка: печатает `ls args: [...]`               |
| `cd [args]` | заглушка: печатает `cd args: [...]`               |
| `exit`      | закрывает эмулятор (с аргументами - ошибка)       |

Неизвестная команда: `<имя>: command not found`.

### Параметры командной строки

| Параметр          | Описание                                    |
|-------------------|---------------------------------------------|
| `--vfs ПУТЬ`      | путь к физическому расположению VFS         |
| `--script ПУТЬ`   | путь к стартовому скрипту                   |
| `--help`          | справка по параметрам                       |

При запуске все заданные параметры выводятся на экран (отладочный
вывод): в окно серым цветом и в консоль. Неизвестный параметр - ошибка
с остановкой программы.

### Стартовый скрипт

Текстовый файл (UTF-8), в каждой строке одна команда эмулятора.
`#` начинает комментарий, пустые строки пропускаются. Команды
выполняются по очереди, на экране видны и ввод, и вывод, как будто их
набирает пользователь. **Скрипт останавливается на первой ошибке**:
показывается номер строки, остальные строки не выполняются, после чего
можно продолжать вводить команды вручную. Если файл скрипта не найден,
выводится ошибка, окно работает как обычно.

Скрипты реальной ОС для проверки параметров (Windows `.bat`, Linux
`.sh`): `scripts/test_config.bat`, `scripts/test_config.sh`. Каждый
запуск открывает окно, закройте его для перехода к следующему.

## 3. Сборка и тесты

Сборка не нужна. Требуется Python 3.8+ с tkinter (на Windows он
ставится вместе с Python).

```
run.bat                                  # запуск, Windows
./run.sh                                 # запуск, Linux/macOS
python -m unittest discover -s tests -v  # тесты
```

## 4. Примеры использования

Запуск со скриптом (параметры задаются после имени скрипта запуска):

```
run.bat --script scripts/stage2.txt
./run.sh --script scripts/stage2.txt
```

Диалог в окне:

```
user@host:~$ ls -l /tmp
ls args: ['-l', '/tmp']
user@host:~$ cd /home
cd args: ['/home']
user@host:~$ foo
foo: command not found
user@host:~$ exit now
exit: too many arguments
user@host:~$ exit
```
